Use `python3 run-cpu.py` from this directory's source checkout to renew the
bounded CPU gates. `verify-browser.cjs` requires an explicitly owned Chrome/WebGPU
lane and the candidate's exact source/package hashes under `INSTRUMENT_PACKAGE`.
It asserts a real AMD adapter and closes its browser/server within eight minutes.
`run-native.py` requires a separate owned native lane, exact candidate hashes,
an unlocked console and fresh library/output paths. Each owned application has
a 120-second deadline and the whole batch has a 300-second inhibitor ceiling.
`collect.py` (Python with Pillow) preserves and verifies actual PNGs/receipts.
Do not substitute a regenerated package for the recorded candidate or imply a
replay ran by running the collection helper.
